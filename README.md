# PO Mastery Academy
### Enterprise Product Owner Learning Portal & 30-Mock Exam Certification Simulator

An enterprise-grade, comprehensive web portal designed for aspiring and practicing Product Owners to master modern product ownership from foundational concepts to advanced executive leadership.

---

## 🌟 Key Features

### 1. 🎓 Comprehensive 10-Chapter Curriculum
Progressive learning roadmap from foundational agility to enterprise executive mastery:
1. **The Product Owner Identity, 8 Stances & P&L Ownership** (Scrum Guide 2020 accountabilities, PO vs PM vs Project Manager, 8 Preferred Stances vs 6 Anti-Patterns, Unit Economics: CAC, LTV, Payback, NRR)
2. **Agile & Scaling Frameworks** (Scrum mechanics, Kanban with Little's Law & Cumulative Flow Diagrams, Scrum.org Nexus, Large-Scale Scrum / LeSS & LeSS Huge, Scaled Agile Framework / SAFe 6.0)
3. **Strategic Prioritization Techniques Masterclass** (Weighted Shortest Job First / WSJF with Cost of Delay, Kano Model questionnaire & curve dynamics, MoSCoW 60/20/20 capacity guardrails, RICE scoring calibration, Value vs Effort 2x2 matrix, Buy-a-Feature workshops)
4. **Strategic Goals, OKRs, KPIs & North Star Metrics** (Outcome vs Output OKRs, North Star Metric input trees: Breadth/Depth/Frequency, Leading vs Lagging indicators, Goodhart's Law & counter-metrics, Scrum.org Evidence-Based Management / EBM 4 KVAs, Pirate Metrics / AARRR, Google HEART)
5. **Design Thinking, Personas & Customer Discovery** (Stanford d.school Double Diamond, Point-of-View / POV & How Might We framing, Actionable Personas vs Anti-Personas, Empathy Mapping: Says/Thinks/Does/Feels, Jobs-to-be-Done / JTBD 4 Forces of Progress, Teresa Torres Continuous Discovery Habits & Opportunity Solution Trees)
6. **Value Stream Mapping (VSM) & Flow Optimization** (Operational vs Development Value Streams, Processing Time vs Lead Time, Flow Efficiency % calculations, Rolled First-Pass Yield %CA, The 8 Lean Wastes / TIMWOODS in software, Goldratt's Theory of Constraints)
7. **User Story Mapping & Advanced Story Slicing** (Jeff Patton 2D narrative mapping, Backbone Activities & User Steps, Walking Skeletons vs MVPs vs MMFs, Henrik Kniberg's transport evolution, Mike Cohn's SPIDR framework, Gojko Adzic's Hamburger Method)
8. **Requirements Hierarchy (Portfolio Epics, Features & BDD Stories)** (SAFe Requirements Hierarchy, Lean Portfolio Management Epic Hypothesis Statements, Business vs Enabler Epics & capacity guardrails, Feature Benefit Hypotheses, 3Cs & INVEST model, Given/When/Then BDD acceptance criteria with error boundaries)
9. **Facilitation Techniques for the Product Owner & Saying 'No'** (High-impact Backlog Refinement agendas, 10% capacity rule & 3 Amigos, single-sentence outcome-driven Sprint Goals, Sprint Reviews using Liberating Structures: 1-2-4-All & Lean Coffee, Mendelow Stakeholder Power/Interest Matrix, verbatim opportunity-cost scripts for saying 'No' to HiPPOs)
10. **Advanced Product Leadership, Product Ops & Technical Debt** (Martin Fowler's Technical Debt Quadrant, incremental modernization via the Strangler Fig Pattern, Product Operations / Product Ops 3 pillars, scientific A/B and painted door testing with statistical significance, Ethical AI governance, algorithmic bias audits & Human-in-the-Loop guardrails)

**✨ Dedicated Market Interview Masterclass in Every Sub-Chapter:** Every sub-chapter features an interactive interview simulation with common corporate questions, the "Trap Answer" (what failing candidates say), the "Senior PO Model Answer" (verbal articulation using economics and telemetry), and behavioral STAR examples.

**End-of-Chapter Assessments:** Every chapter concludes with an interactive 5-question scenario quiz providing instant scoring, detailed explanations, and an 80% passing mastery benchmark.

## 🚀 Quick Start Guide

### 1. Installation
```powershell
cd C:\Users\anany\.gemini\antigravity\scratch\po-mastery-academy
npm install
```

### 2. Run Automated Test Suite
```powershell
npm test
```

### 3. Launch the Application
To run the Vite development server:
```powershell
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

To run the unified production server:
```powershell
npm run build
npm start
```
Open [http://localhost:5000](http://localhost:5000) in your browser.

## ⚡ Deploy to Vercel

The repository is pre-configured with `vercel.json` and an `/api` serverless handler for 1-click deployment on Vercel:

### Option A: Via Vercel Web Dashboard (Recommended)
1. Go to [https://vercel.com/new](https://vercel.com/new).
2. Connect your GitHub account and import **`santoshadkar/po_mastery_academy`**.
3. Vercel automatically detects the build settings:
   - **Framework Preset**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. Click **Deploy**. Vercel will build and assign you a live HTTPS production domain (`https://po-mastery-academy.vercel.app`) in ~45 seconds!

### Option B: Via Vercel CLI
```bash
npm install -g vercel
vercel
```
